
# Social Media Crisis Detection System

A Python-based project to detect and analyze crises from social media posts using sentiment analysis and keyword detection.

## Features
- Detects potential crisis-related posts
- Sentiment analysis of social media content
- Simple web interface built with Flask
- Database integration

## Tech Stack
- Python
- Flask
- SQLite

## How to Run
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `python app.py`
